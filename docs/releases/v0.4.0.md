# ARAM v0.4.0

Android의 저장 데이터 보존과 파일 내보내기를 개선하고, 일부 SKT·LGT 게임의
호환성을 높였습니다. 모바일 화면 탐색과 브라우저 저장 기능도 다듬었습니다.

## 주요 변경

- Android 앱을 백그라운드로 보낼 때 실행 중인 게임의 저장 데이터를 기록해,
  이후 앱이 종료되어도 진행 상황을 복원할 수 있게 했습니다.
- 저장 데이터 백업과 디버그 ZIP을 Android 문서 선택기에서 고른 위치로
  내보낼 수 있습니다.
- 모바일 햄버거 메뉴에 탐색 항목과 설정 진입점을 추가했습니다.
- 브라우저 버전에서 게임별 저장 데이터를 브라우저 저장소에 보존합니다.
- 일부 SKT GVM 게임의 화면·숫자 키 입력을 연결하고, 진단 정보를 보강했습니다.
- 일부 LGT WIPI/Java 게임의 실행, 화면 표시, 미디어 전환과 입력 처리를
  개선했습니다.
- LGT Raptor 게임의 화면 좌표, 배경음 재생, Java 배열 처리와 실행 안정성을
  개선했습니다.

호환성은 게임 파일의 해시와 프로필에 따라 달라집니다. BREW·GVM 실행은
게임별로 검증된 단계가 다르며, 모든 게임의 완전 실행을 뜻하지 않습니다.

## Android 배포

GitHub에서 배포하는 Stable APK와 Google Play용 AAB는 같은 소스에서
빌드됩니다. Play 빌드는 앱 자체 업데이트 기능을 숨기고 Play를 통해
업데이트합니다. Play App Signing 인증서가 GitHub APK의 인증서와 다르면
기존 앱 위에 Play 버전을 설치할 수 없습니다. 설치 방식을 바꾸기 전에
저장 데이터 백업을 내보내세요.

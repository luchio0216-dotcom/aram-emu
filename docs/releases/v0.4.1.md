# ARAM v0.4.1

Android 릴리즈 빌드의 DEX 코드와 리소스 최적화를 적용한 패치 릴리즈입니다.

## Android 최적화

- Android Gradle Plugin 9.0.1과 Gradle 9.1.0으로 빌드 도구를 업데이트했습니다.
- R8 코드 축소, 논리 최적화와 난독화를 Stable APK 및 Google Play AAB에
  적용했습니다.
- 사용하지 않는 Android 리소스를 릴리즈에서 제거합니다.
- Play 릴리즈 후보 빌드에서 R8 매핑과 제거 보고서가 생성되고 실제 클래스
  난독화가 수행되는지 자동으로 확인합니다.

이 변경은 Google Play의 DEX 코드 최적화 진단에 대응하며 앱의 Java/Kotlin
코드와 포함된 Android SDK 코드의 크기와 런타임 부담을 줄입니다. 에뮬레이터의
Go 네이티브 라이브러리와 게임 데이터 형식은 변경하지 않습니다.
